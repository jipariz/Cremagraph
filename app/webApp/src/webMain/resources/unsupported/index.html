WEBKIT 27.2

THE EDITOR CANNOT RUN IN THIS BROWSER.

This version of WebKit cannot draw the editor's canvas, so the page comes up blank. It is one engine across Apple's platforms: an iPhone or iPad on 27.2 is affected whichever browser you open, and so is Safari 27.2 on a Mac.

Updating past 27.2 is the fix. Switching browser is not: on an iPhone or iPad they all run the engine that is broken.

OPEN THE EDITOR ANYWAY

There is also an Android app: OnlyShots on Google Play.
